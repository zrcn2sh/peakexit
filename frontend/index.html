📐 매도 로직 설명

① 손절 (Stop Loss)
수익률이 설정값 이하로 떨어지면 즉시 시장가 매도.
② 트레일링 스탑 ("어깨")
ATR 자동 계산 우선 → 실패 시 폴백값 사용. 고점 대비 N% 하락 시 매도.
③ 목표가 (Take Profit)
설정한 수익률 즉시 전량 매도. 선택 항목.

📊 종목별 ATR 트레일링 설정

🟢 high = ATR 데이터 기반 자동 계산  |  🟡 medium = 부분 데이터  |  🔴 low = 분류 기본값(폴백) 적용
트레일링 하락폭: ATR(14일) × 분류별 배수 → 상한/하한 범위 내 클램프

📱 텔레그램 봇 명령어

텔레그램에서 봇에게 직접 명령어를 입력하면 즉시 응답합니다.
매도 신호/결과/리포트는 자동으로 전송됩니다.
/holdings
현재 보유종목 전체 현황
수익률 + 고점대비 + 트레일링 비율 + 매도신호 표시
/summary
포트폴리오 수익 요약
시드머니 기준·보유(매입원가) 기준 수익률·손익 + 추정 자산
/overview · /현황
수동 전체 현황
/summary 와 /holdings 를 잔고 1회 조회로 연속 발송 (텔레그램 2통)
/atr
종목별 ATR 트레일링 설정 조회
ATR% + 트레일링 하락폭 + 신뢰도 확인
/status
시스템 상태 확인
자동매도 활성화 여부 + 투자모드 + 현재 설정값
/check
즉시 매도 검사 실행
스케줄 무시하고 지금 바로 전종목 검사
/help
도움말 표시
전체 명령어 목록 안내
